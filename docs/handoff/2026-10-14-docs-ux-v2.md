## 3 首次使用的程式依據

`desktop/src/app.js` 在本機 managed 安裝沒有 BAT 主機時開 Settings。
`managed-setup.js` 與 `desktop/DESIGN.md` 的 Setup glossary 定義：

1. 「準備開始工作 → 1. 連線至 BAT」先展開。
2. 密碼欄接收 BAT 連線網址，在本機拆出位址、權杖與指紋；核對主機代號。
3. 按「驗證並儲存主機」才提交。成功後連線步驟收合，「查看工作階段」是下一步。
4. 儲存庫、驗證命令及受管工作權限需要時再展開，不是閱讀工作階段的前置條件。
5. 結果未知保留原請求與 key，使用「查回請求」。連線不改人工資源的唯讀身分。

本機 Git transport 與 Overview PM 判讀仍只有設計。
