## 3 資源收集的實作邊界

完整設定及資料合約見 [Agent resource observations](../design/agent-resource-observation.md)。

- **明確連接本機來源。** 管理員在 `[usage]`／`[[usage.sources]]` 指定既有 workspace、原 CLI session、絕對 JSONL 路徑、adapter 與角色；預設沒有來源。支援 `codex-rollout-v1`、`claude-transcript-v1`，每輪有讀取上限。不掃描家目錄、不啟動 CLI、不呼叫 provider。來源授權只允許讀取，不代表取得 session 管理權。
- **中央持續收集。** TaskDaemon 在既有 daemon lease 下執行 collector，與是否開啟頁面無關。資料、cursor、去重狀態及配額快照使用 `Journal.tx()` 同批提交。兩張新增表採冪等 DDL，沒有配置新的 `user_version` 或資料遷移步驟。
- **來源變更不偷偷重算。** 拒絕 symlink、pipe、device；檔案替換、截短、觀測到的改寫、衝突或格式錯誤會撤回衍生數值並保留 cursor。綁定變更產生 `binding_changed`，不同綁定須使用新審查的 source ID。讀取後重新檢查 lease 和有效綁定。
- **不同 CLI 分別計數。** Codex 使用累計值差分，cache 是 input 的子集、reasoning 是 output 的子集；requested model 不假稱 actual model，呼叫數未知。Claude 以原 message ID 去重，符合規則的單調修訂取代同筆 receipt；只有各必要欄位齊備才合計 input、cache read、cache creation、output。reported messages 不等於全部 API calls。
- **配額與耗量分開。** 只有來源提供且仍新鮮的 Codex rate-limit window，加上明確 opaque pool，才投影配額。依 pool 與 limit ID 取最新報告，不相加共享帳號餘額；缺失、過期或同時衝突保持未知。尚無跨中央 federation。Token 不換算為訂閱剩餘 token 或金額。
- **所有入口共用投影。** HTTP `GET /api/v1/pm/workspaces/{workspace_id}/resources` 與 RPC／MCP `pm_resources_get` 核對當下 membership 和 observe scope；Tauri 僅允許精確唯讀路由。預設七天，時間區間為起點含、終點不含，最大 366 天。API 不回傳原路徑、session ID、提示內容或憑證。
- **前端呈現有界事實。** EN／zh-TW 共用頁提供 1／7／30／90 天及 CLI／model／role 篩選，篩選的是來源，來源總量不是各模型效能歸因。配額另表顯示當下新鮮值。暫停只凍結畫面；離開頁面停止輪詢。讀取失敗撤回資料，遲到回應不復活舊值。
