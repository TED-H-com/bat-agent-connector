6. 後續工作按原 W 編號與剩餘範圍推進；真人操作另有責任，不在這次文件任務中擅自執行。

本機 heavy pytest／Cargo／UI 順序執行，使用共享 check lock。
pytest 一律用 `pytest-disktmp`，磁碟臨時目录結束清除，不使用 `/dev/shm` 或 tmpfs。
測試不寫 live BAT／provider，不留 task-owned container，也不清理他人資源。

## 8. 實際試用前提

Web／Tauri 是 client，Python 中央保存帳本，所選 BAT host 執行工作，三者可在不同電腦。
Windows／Mac 的本機中央不提供 `codex-native-linux`；可用合格 Linux BAT binding，
或明確加入 Linux 中央。專用 PM runtime 需要固定 Codex 0.160.0 與 bubblewrap；
BAT 一般 bundled Codex 0.159.2 不代替它。依現有合約配置，不調整主機政策繞過拒絕。

AHP observer 只讀固定支援的 protocol profiles，沒有 create/send/stop 或 live host 接受證據。
SSH alias、key、known-hosts 在中央服務帳號所在主機準備，不會從瀏覽器轉送。
請依 [首次使用](../getting-started.zh-TW.md)建立專用小範圍試用，保存精確版本、原 operation、
assessment、release 及維護 receipts；這份交接沒有宣稱 owner 已執行它。
