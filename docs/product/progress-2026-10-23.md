## 尚未完成 / Still open

Fleet Apply 與 detach 仍不可供使用者完成；參與者紀錄、探索與傳輸已合併，正式執行仍未接通。
下表列出 Windows 套用連線及其他仍缺的能力；「審查中」不表示已合併或可用。
AHP 自有工作與原生 coding 也尚無可供使用者執行的正式入口。
設計依據見 [Fleet 設定](../design/fleet-configuration.md)、[建立證據](../design/fleet-creation-evidence.md)、
[關聯檢閱](../design/connection-reference-review.md)、[原生 session 證據](../design/native-session-journal.md)
與 [AHP 邊界](../design/pm-ahp-observer.md)。

but production execution is not connected. The table lists the capabilities still needed on Windows and elsewhere;
