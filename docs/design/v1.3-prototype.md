# v1.3 E00 互動原型（R0 審閱）

本原型供負責人在同一個 Dashboard 完成「第一句 → 計畫 → 工作 → 第二句 → 成果 → 決策 → 返回」。
資料為合成 fixture，狀態僅存在記憶體；不連接 Connector、BAT、GitHub 或模型。
這是 E00／R0 的互動證據，尚未完成 E01–E11，也不是 R1–R5 的實機驗收。

## 建置與開啟

```bash
cd desktop
npm run build:prototype
node tests/static-server.mjs
```

以測試伺服器設定的連接埠開啟 `/prototype/v1.3/`。`BATC_UI_TEST_PORT` 決定連接埠；未設定時為 1421。
`?lang=en` 或 `?lang=zh-TW` 切換語言，`?scene=running` 等參數可直接開啟場景。
產物在被 Git 忽略的 `desktop/dist-prototype/v1.3/`；資源路徑皆相對，包含 noindex，沿用嚴格 CSP。
原型不修改正式執行程式。Pages 工作流程將產物放入 `/prototype/v1.3/`。
負責人於 2026-10-15 要求保留公開 demo，並繼續完成正式功能；網站現在從專案介紹連到
`/demo/` 的正式 Dashboard 展示，再提供本原型的入口。這項公開展示授權不等於實機 R1 驗收。
完整專案站台路徑為 `/bat-agent-connector/prototype/v1.3/?lang=zh-TW`（英文使用 `?lang=en`）；由整合者合併後的 Pages 部署提供，分支上的本機驗證不代表已上線。

頂端獨立的原型列預設只有一行：目前場景和展開鈕。展開後才有語言、重設、主題、黃金句填入、
PM 無法使用、部分失敗、工作狀態、Hermes 到達、斷線、PM 評估、外部合併／部署事件與安全計數。
計數表示模擬狀態的變化，並不代表真實模型呼叫。切換場景會重設記憶體狀態；切換產品檢視保留草稿。

## 場景與驗收對照

### 公開 Dashboard 展示與原型的界線

`desktop/demo/` 直接建置 `desktop/src/main.ts` 與現有雙語元件，以建置時的 transport
替換讀取 `desktop/tests/demo/` 合成資料；不複製需求、看板、時程等視圖。安裝版與一般
Web 建置不載入這個 transport。執行 `cd desktop && npm run build:demo`，產物在
`desktop/dist-demo/`，Pages 發布到 `/demo/`。`?lang=en`／`?lang=zh-TW` 選擇語言，
`?view=requirements` 等參數開啟固定的八個專案視圖；原有 hash deep link 也可使用。

展示可瀏覽、搜尋、篩選、展開詳情與閱讀 session。展示 transport 只允許 GET，所有
mutation 回報拒絕；CSP 的 `connect-src 'none'` 阻擋網路連線，沒有 fallback 到中央。
合成專案身分與展示偏好使用獨立 namespace，重設只清除此 namespace。畫面上持續顯示
合成資料及無 BAT／模型連線的說明。採用、執行、驗收等互動模擬仍在 v1.3 原型，
不能把唯讀展示或原型當成真實執行證據。

原型中需求、時程、相依、問題、代理、看板及全域工具不再顯示 placeholder；其連結以
新分頁開啟正式展示的對應視圖，保留原型的草稿與工作。八個正式視圖及搜尋、深連結、
語言、重設與無網路行為由 `desktop/tests/public-demo.spec.ts` 直接測試發布用 bundle，
不安裝 Playwright route mock 或假 Tauri bridge。既有原型測試繼續驗證模擬工作流程。

## 2026-10-15 審閱回饋後的互動方向

負責人表示個人測試仍待安排，並要求持續推進體驗。以下修正供下一次試用；不代表 R0、R1 或實機驗收已通過。

1. **採用後的落點**：「採用，稍後做」留在討論；「採用並開始」直接開啟準備中的工作。計畫、草稿及步驟可隨時查回。
2. **首次檢視成果**：建議保留交付狀態與建立 PR；檔案、差異、測試按需展開，手機開同一個成果抽屜。
3. **決策位置**：工作成果、討論側欄、總覽共用同一份 PM 評估與決策。記錄後留在原畫面，其他入口即反映同一結果。
4. **下一輪輸入**：建議忙碌時一律先排下一輪；佇列編輯／取消能力依中央提供的可靠回執，原型不先承諾。
5. **跨控制者協作**：建議預設送 Hermes 收件匣，由原控制者依政策讀取；需要立即獨立推進時另開自己的工作。

## 驗證與證據

`desktop/tests/prototype-v1-3.spec.ts` 在英文／繁中、1440／390 驗證黃金流程與七種工作狀態，
另在中英文、1440／768／390 驗證成果與討論決策入口的一致性，並確認開始後可返回草稿及已採用計畫。保留零模型筆記、下一輪非改向、人工／Hermes 零寫入、原 key 恢復、零重複啟動及六種交付狀態斷言。
產品區域驗證沒有規格術語、進階資料外的內部 ID、英文殘留、原始鍵、行內 style 或橫向溢出。
測試只請求相對的靜態原型資源，並檢查 console 錯誤。

預設執行不寫入任何截圖或錄影，不建立、清除或刪除證據目錄。測試以 `?scene=` 分成四段，
並保留「筆記 → 啟動 → 下一輪排程 → 已傳送」的短連續流程；各段使用 Playwright 預設的 30 秒限制。
原型 spec 的 `beforeAll` 在第一次導覽前重新建置一次，確保測到目前來源；共用伺服器只讀取產物，
缺少原型時回傳 404，不會讓其他 Dashboard spec 等待建置。`fullyParallel` 關閉，同一檔案在一個 worker 執行；
其他 spec 不建置原型。

證據必須明確啟用並指定目錄：

```bash
cd desktop
BATC_PROTOTYPE_SHOTS=1 BATC_PROTOTYPE_SHOT_DIR="$TMPDIR/shots" \
  heavy npx playwright test tests/prototype-v1-3.spec.ts
```

此模式才執行完整連續流程並將單一流程限制延長至 120 秒，供截圖／錄影使用；預設測試不延長限制。
沿用 `01`–`17` 命名，另有工作狀態補圖、PM 三態評估、合併／部署分離、衍生確認／新工作、Hermes 獨立工作、
討論決策返回、768px 及三張 `compare-*-en-1440.png`。可用 `BATC_PROTOTYPE_SHOT_FILTER` 正規表示式只重拍指定檔名。
需要錄影時另設 `BATC_PROTOTYPE_VIDEO_DIR`；每段錄影建立自己的唯一子目錄，內含 `golden-flow-<語言>-1440.webm`。
不設定即不錄影；測試不刪除任何既有檔案。這些產物不加入 repository。

## 場景連續性規則（R0 修正）

- **筆記**：儲存成功後清空輸入框，原訊息留在同一串，標記「筆記・未傳送給 PM」。
  可以稍後使用該筆記的「傳送給 PM」；傳送成功只更新同一筆記為已傳送，不再附加第二筆。
  若在輸入框重送同一份尚未傳送的筆記文字，也沿用該筆記。傳送不可用時保留草稿，不建立 PM 回覆。
  綠色儲存狀態只屬於當次儲存，下一個輸入、切換意圖、切換檢視或傳送動作即清除；筆記本身的標記保留；PM 警告佔用高度後，討論會捲到該筆記，避免看似消失。
- **下一輪**：排程成功後輸入框清空，只有回執保留文字；排程失敗時只顯示失敗與原草稿，不產生回執。
  執行中的提示為「本輪結束後才會送出」，中斷是獨立動作。當本輪結束，回執轉為 mei.lin 的一筆已傳送訊息，
  下一輪處理失敗後重試案例；後續摘要及成果場景只顯示已傳送，不再顯示排程回執。本輪結束／待驗證時，
  空白輸入框的「送出下一步」可用，提示為「送出後開始下一輪」。
- **等待輸入**：本輪暫停在明確問題，尚未完成。下一步仍先儲存，待問題回答後才送出，
  不提供「中斷」或「本輪結束後才會送出」提示，避免把回答問題和改向目前執行混為同一操作。
- **啟動紀錄**：首次採用後保留八步展開結果（圖 06）；開啟工作後，討論只留「工作已開始」、
  「開啟工作」和預設收合的詳細資料，原始八步結果仍可查閱。
- **決策**：總覽記錄一次決策後移除決策按鈕，討論新增帶有 mei.lin、時間及總覽連結的訊息。
  討論標籤和清單跟隨已驗收、已合併、已部署的交付證據，不再停在成果待驗證。
- **合併後摘要**：採用更新摘要的方式；已驗收時先改為審閱 PR #48，不再要求重複驗收；已合併時來源改為 PR #48 已合併，建議部署後確認；
  已部署時增列部署來源，建議持續觀察登入與重試。不保留已過時的「PR 開啟／等待合併」建議。
  原型列同步顯示目前交付場景。近期交付不重複顯示內層交付標題。
  驗收只更新該需求的決策紀錄；摘要列與專案章程仍保留尚未決定的復原支援預算。
- **短畫面**：側欄維持產品的整欄捲動，五筆工作時仍能捲到待處理、工具和設定。
  衍生確認沿用原生對話框的焦點限制與 Escape，另外以固定全視窗遮罩覆蓋所有背景。
  公開工具活動依時間排列：已完成在前，執行中在後，沿用產品的完成／執行中狀態標籤與圖示。
