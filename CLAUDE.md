# Claude Code repository guide

Read [AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md) before working.
Their repository, ownership, authorization and disk-backed testing rules apply here.

Start with the [November 10 handoff](docs/product/claude-code-handoff-2026-11-10.md),
then the [current agent handoff](docs/product/v1.3-agent-handoff.md) and
[implementation status](docs/product/implementation-status.md). Fetch and inspect
current `origin/main`; dated handoff SHAs are snapshots, not instructions to reset
or overwrite newer work. Use an isolated worktree and preserve unrelated changes.

The November 10 handoff distinguishes merged #511 from published 0.2.17, maps the
next work and code entry points, and records validation, release and live-acceptance
boundaries. It does not replace the product plans or authorize production-host work.
